# my-new-project

카드/전략 기반 웹게임 프로토타입. 로그(전투 기록) 중심으로 턴이 진행되며, 가벼운 웹 스택으로 시작해 추후 2D RPG와 모바일 앱스토어 출시까지 확장하는 것을 목표로 합니다.

## 아키텍처

게임 로직과 UI를 분리해서, 나중에 렌더러만 교체하면 2D RPG로 확장할 수 있도록 설계했습니다.

- `src/engine/` — 순수 TypeScript 함수로 작성된 게임 엔진 (`engine.ts`, `cards.ts`, `races.ts`, `monsters.ts`, `essence.ts`, `gear.ts`, `stats-calc.ts`, `stat-bonus.ts`, `profile.ts`). 카드 사용, 턴 진행 등 모든 액션이 `GameState`를 새로 계산하고 `log` 배열에 이벤트를 기록합니다. DOM이나 렌더링에 전혀 의존하지 않아 UI를 바꿔도 그대로 재사용 가능합니다.
- `src/ui/` — 화면별 렌더링 (`menu`, `character-select`, `stats`, `inventory`, `equipment`, `essence`, `battle`). `src/main.ts`는 화면 전환만 담당하는 라우터입니다. 나중에 Phaser 기반 2D 렌더러로 교체해도 엔진은 그대로 둘 수 있습니다.

## 시작하기

```bash
npm install
npm run dev       # 개발 서버 실행
npm run build      # 프로덕션 빌드 (dist/)
```

## 현재 구현된 것

- 메인 메뉴에는 "게임 시작" 버튼만 있고, 인벤토리/장비창/정수창은 게임 진입 후(캐릭터 정보 화면, 전투 화면) 안에서만 접근 가능
- 종족 선택 → 캐릭터 정보(스텟창) → **미궁 입장**. 승리/패배 후에는 메인 메뉴로 튕기지 않고 "다음 층으로"/"다시 도전"이 기본 동작이라 계속 이어서 플레이 가능 (메인 메뉴 복귀는 작은 보조 링크)
- **미궁(던전) 진행**: 미궁 입장 시 1층부터 시작, 승리할 때마다 층이 1씩 올라감(패배하면 같은 층 재도전). 층(F)에 등장하는 몬스터 등급은 F·F+1이 주류(약 80%)이고 F+2 등급이 가끔(약 20%) 나오도록 가중치를 둠 — 예: 1층은 1~2등급이 주류, 가끔 3등급
- 종족별 고정 스텟(체력/마나/공격/방어 보너스): 인간, 엘프, 오크, 드워프
- 플레이어 vs 몬스터 턴제 카드 배틀 (공격/방어/회복 카드), 마나 기반 카드 사용, 자동 적 AI 턴
- 몬스터 등급(1~10)에 따른 경험치 획득, 같은 이름의 몬스터는 최초 처치 시에만 경험치 지급
- 레벨/경험치는 `localStorage`에 저장되어 브라우저를 다시 열어도 유지됨, 스텟창에 표시
- **정수(essence) — 흡수형 장착**: 몬스터 처치 시 0.1% 확률로 그 몬스터 고유의 정수가 드랍. 그 자리에서 흡수할지 버릴지만 선택 가능 (별도 보관 없음). 흡수하면 레벨당 1개씩 열리는 슬롯에 순서대로 영구 장착됨 (해제 UI 없음 — 특수한 방법으로만 해제 가능). 각 정수는 드랍된 몬스터의 특성을 반영한 고정 스텟 보너스 + 전용 스킬 카드를 부여
- **장비(무기/방어구/장신구) — 몸에 착용하는 일반 장비**: 정수와 완전히 별개 시스템. 몬스터 처치 시 3% 확률로 드랍되어 인벤토리에 자동으로 담기고, 장비창에서 자유롭게 장착·해제 가능 (해제하면 다시 인벤토리로)
- 장착한 정수와 장비의 스텟 보너스는 모두 종족 스텟에 합산되고, 정수 스킬은 전투 덱에 추가됨
- **화면 3분리**:
  - `인벤토리` — 마석(처치 시 5% 확률로 드랍, 자동 보관), 미착용 장비, 금화 표시(금화는 드랍되지 않고 표시만)
  - `장비창` — 무기/방어구/장신구 슬롯. 자유롭게 장착·해제
  - `정수 창` — 지금 장착 중인 정수 목록 + 지금까지 발견한 정수 도감(흡수 안 해도 발견 기록은 남음)
- 모든 행동이 로그로 기록되고 화면에 누적 표시
