# my-new-project

카드/전략 기반 웹게임 프로토타입. 로그(전투 기록) 중심으로 턴이 진행되며, 가벼운 웹 스택으로 시작해 추후 2D RPG와 모바일 앱스토어 출시까지 확장하는 것을 목표로 합니다.

## 아키텍처

게임 로직과 UI를 분리해서, 나중에 렌더러만 교체하면 2D RPG로 확장할 수 있도록 설계했습니다.

- `src/engine/` — 순수 TypeScript 함수로 작성된 게임 엔진 (`engine.ts`, `cards.ts`, `races.ts`, `monsters.ts`, `essence.ts`, `profile.ts`). 카드 사용, 턴 진행 등 모든 액션이 `GameState`를 새로 계산하고 `log` 배열에 이벤트를 기록합니다. DOM이나 렌더링에 전혀 의존하지 않아 UI를 바꿔도 그대로 재사용 가능합니다.
- `src/ui/` — 화면별 렌더링 (`menu`, `character-select`, `stats`, `inventory`, `battle`). `src/main.ts`는 화면 전환만 담당하는 라우터입니다. 나중에 Phaser 기반 2D 렌더러로 교체해도 엔진은 그대로 둘 수 있습니다.

## 시작하기

```bash
npm install
npm run dev       # 개발 서버 실행
npm run build      # 프로덕션 빌드 (dist/)
```

## 현재 구현된 것

- 메인 메뉴 → 종족 선택 → 캐릭터 정보(스텟창) → 전투 화면 흐름
- 종족별 고정 스텟(체력/마나/공격/방어 보너스): 인간, 엘프, 오크, 드워프
- 플레이어 vs 몬스터 턴제 카드 배틀 (공격/방어/회복 카드), 마나 기반 카드 사용, 자동 적 AI 턴
- 몬스터 등급(1~10)에 따른 경험치 획득, 같은 이름의 몬스터는 최초 처치 시에만 경험치 지급
- 레벨/경험치는 `localStorage`에 저장되어 브라우저를 다시 열어도 유지됨, 스텟창에 표시
- **정수(essence) 시스템**: 몬스터 처치 시 0.1% 확률로 그 몬스터 고유의 정수가 드랍. 인벤토리에 바로 담을 수는 없고, 그 자리에서 흡수할지 버릴지만 선택 가능
  - 흡수하면 레벨당 1개씩 열리는 장착 슬롯에 순서대로 영구 장착됨 (해제 UI 없음 — 특수한 방법으로만 해제 가능하다는 설정)
  - 각 정수는 드랍된 몬스터의 특성을 반영한 고정 스텟 보너스 + 전용 스킬 카드를 부여
  - 장착한 정수의 스텟은 종족 스텟에 합산되고, 스킬은 전투 덱에 추가됨
  - 인벤토리 화면(메인 메뉴 → 인벤토리)에서 슬롯 현황과 장착된 정수 확인 가능
- 모든 행동이 로그로 기록되고 화면에 누적 표시
