# my-new-project

카드/전략 기반 웹게임 프로토타입. 로그(전투 기록) 중심으로 턴이 진행되며, 가벼운 웹 스택으로 시작해 추후 2D RPG와 모바일 앱스토어 출시까지 확장하는 것을 목표로 합니다.

## 아키텍처

게임 로직과 UI를 분리해서, 나중에 렌더러만 교체하면 2D RPG로 확장할 수 있도록 설계했습니다.

- `src/engine/` — 순수 TypeScript 함수로 작성된 게임 엔진 (`engine.ts`, `cards.ts`, `races.ts`, `monsters.ts`, `dungeon.ts`, `essence.ts`, `gear.ts`, `stats-calc.ts`, `stat-bonus.ts`, `profile.ts`, `auth.ts`, `cloud-profile.ts`, `supabase-client.ts`). 카드 사용, 턴 진행 등 모든 액션이 `GameState`를 새로 계산하고 `log` 배열에 이벤트를 기록합니다. DOM이나 렌더링에 전혀 의존하지 않아 UI를 바꿔도 그대로 재사용 가능합니다.
- `src/ui/` — 화면별 렌더링 (`auth`, `menu`, `character-select`, `stats`, `dungeon-map`, `inventory`, `equipment`, `essence`, `battle`). `src/main.ts`는 화면 전환만 담당하는 라우터입니다. 나중에 Phaser 기반 2D 렌더러로 교체해도 엔진은 그대로 둘 수 있습니다.
- **세이브 데이터 필드 추가 원칙**: `PlayerProfile`/`ResumeSession`에 새 필드를 추가할 때는 반드시 (1) `defaultProfile()`에 기본값을 넣고 (2) `sanitizeProfile()`(`profile.ts`)/`sanitizeResumeSession()`(`session.ts`)에도 그 필드의 방어적 기본값 처리를 같이 추가하세요. 이 두 함수가 로컬(`loadProfile`)과 클라우드(`loadCloudProfile`) 저장분을 모두 통과하는 유일한 관문이라, 여기 안 거치면 그 필드가 없는 구버전 세이브에서 `undefined`가 그대로 흘러들어와 조용히 깨질 수 있습니다 (실제로 `floor2Zones` 필드 추가 후 이 처리를 빠뜨려서 구버전 계정의 "이어하기"가 무반응이 되는 버그가 있었습니다).

## 시작하기

```bash
npm install
npm run dev       # 개발 서버 실행
npm run build      # 프로덕션 빌드 (dist/)
```

## 현재 구현된 것

- **로그인 / 클라우드 저장**: 앱 진입 시 아이디·비밀번호로 로그인하거나 "게스트로 계속하기"를 선택. 로그인하면 진행 상황(레벨, 인벤토리, 장비, 정수 등)이 [Supabase](https://supabase.com) 계정에 저장되어 다른 기기에서도 이어할 수 있고, 게스트는 이 브라우저의 `localStorage`에만 저장됨. 로그인 없이도 게임은 항상 완전히 동작함 (설정 방법은 `supabase/README.md` 참고)
  - 내부적으로 "아이디"를 가짜 이메일로 변환해 Supabase Auth의 이메일/비밀번호 로그인을 그대로 사용하므로, 나중에 실제 이메일 인증이나 구글 등 소셜 로그인으로 확장할 때 설정만 추가하면 됨 (게임 로직 변경 불필요)
  - 계정에는 `is_admin` 플래그가 있어 향후 관리자 전용 기능의 기반이 됨. 일반 로그인 경로로는 스스로 켤 수 없고 Supabase SQL Editor에서만 설정 가능 (`supabase/README.md`의 "admin 계정 만들기" 참고). 로그인 시 관리자 계정이면 메인 메뉴에 "관리자" 표시가 뜸
- **캐릭터는 계정당 1개만 존재**: 메인 메뉴 버튼이 캐릭터 유무에 따라 자동으로 바뀜 — 캐릭터가 없으면 "캐릭터 생성"(종족 선택으로 이동), 있으면 "이어하기"(종족 선택을 건너뛰고 바로 진행). 사망 시 세이브 전체 초기화와 자연스럽게 맞물려, 죽고 나면 다시 "캐릭터 생성"이 뜸
  - 종족 선택은 마을 진입 순간 확정됨. 마을의 "뒤로" 버튼은 캐릭터가 아직 없을 때(생성 과정 중)만 보이고, 캐릭터가 이미 있으면 아예 뜨지 않아 다시 종족 선택으로 돌아가 덮어쓸 방법이 없음
- **이어하기 = 종료 직전 화면 그대로 복원**: 마을/스텟창/상점/도서관은 물론, 미궁 탐험 중이던 정확한 위치(미로 구조 포함)나 **전투 중이던 상태(카드 패, 덱 순서, HP, 로그까지)** 도 그대로 복원됨. 화면 전환·전투 진행이 있을 때마다 저장되므로 언제 닫아도 정확히 그 지점부터 이어짐
  - 마을에 "게임 종료" 버튼이 있어 메인 메뉴로 돌아갈 수 있음. 로그아웃이나 세이브 초기화가 아니라 순수 화면 이동일 뿐이라 진행 상황(레벨/골드/시계 등)은 그대로 유지되고, 메인 메뉴에서 "이어하기"를 누르면 나가기 직전 마을로 정확히 복귀함. 판단 대기 패널이 떠 있는 동안은 다른 마을 버튼들과 마찬가지로 비활성화됨
- **미궁에 들어가면 스스로는 되돌릴 수 없음**: 미궁 진입 후엔 탐험을 계속하거나 사망(전체 초기화)하는 것 외에 마을로 되돌아갈 방법이 없음 — "메인 메뉴로" 같은 탈출 버튼이 없음. 잠시 멈추고 싶다면 탭을 닫았다가 나중에 "이어하기"로 정확히 같은 지점부터 재개하면 됨. 예전엔 미궁 안에서 마을로 나갔다가 새 미궁으로 재진입하면 이미 발견한 포탈의 경험치 보너스를 위험 부담 없이 무한 반복 획득할 수 있었는데, 이 탈출구 자체를 없애 막음. 다만 아래 "미궁 내부 시계"에 의한 **강제 귀환**은 예외 — 이건 플레이어가 원해서가 아니라 시간이 다 되어 자동으로 일어나는 것
- 인벤토리/장비창/정수창은 게임 진입 후(캐릭터 정보 화면, 마을, 탐험/전투 화면) 안에서만 접근 가능
- 종족 선택 → **마을** → 캐릭터 정보(스텟창) → **미궁 입장**
  - 마을에서 인벤토리·장비창으로 바로 이동 가능(뒤로 가면 다시 마을로)
  - 마을에 "상점"·"도서관" 진입점이 있음 — 현재는 진입/이탈만 가능한 빈 화면이고, 실제 품목/콘텐츠는 이후 별도 작업에서 채울 예정
  - **마을 시계**: 게임 내 하루 = 실시간 60초. 앱이 열려있고 활성 미궁 런이 없을 때만 흐름(미궁 안에서는 멈춤, 탭을 닫아도 멈춤). 마을 화면에 현재 며칠째·몇 시인지 표시되고, 1×/2×/4× 배속과 "다음 판단 시점까지 스킵"(30일 주기 오전 6시 지점으로 즉시 이동) 가능
  - **미궁 입장은 더 이상 아무 때나 즉시 할 수 없음**: 예전엔 스텟창의 "미궁 입장" 버튼으로 언제든 바로 들어갈 수 있었지만, 지금은 그 버튼이 "미궁 입장까지 남은 시간" 표시로 바뀌었고(마을·스텟창 양쪽), 게임 내 30일마다 오전 6시가 되면 마을 화면에 **입장 여부를 묻는 판단창**이 뜸 — 이때만 입장 가능. 판단창이 뜨면 실시간 30초 안에 "입장한다"/"거부한다"를 선택해야 하고, 응답이 없으면 자동으로 거부 처리되며 시계는 계속 흐름 (다른 마을 화면에 있었다면 마을 화면으로 돌아오는 즉시 판단창이 뜸, 그동안은 마을의 다른 모든 버튼이 잠김). "거부"해도 성과는 그대로 유지되고 다음 판단 시점을 기다리면 됨
- **미궁 탐험 (1층: 원형 미로, 2층: 구역별 4개의 별개 미궁)**
  - **1층 구조**: 중심부(1칸) + 중간 고리(8칸) + 가장자리 고리(8칸, 그중 4칸이 동서남북 포탈)로 이루어진 원형 미로. 중심부↔중간 고리↔가장자리 사이의 통로는 매번 랜덤 생성되어 막다른 길이 있을 수 있지만, **가장자리 고리는 항상 완전히 순환 연결**되어 있어 포탈끼리는 물론 어떤 가장자리 칸에서도 막힘 없이 동서남북을 오갈 수 있음 (1000회 생성 시뮬레이션에서 항상 성립 확인)
  - 각 칸마다 실제로 뚫려있는 방향만 이동 선택지로 제공됨 (칸에 따라 개수가 다름)
  - 구역마다 테마에 맞는 몬스터가 출몰 (북쪽은 언데드, 동쪽은 야수, 남쪽은 인간형, 서쪽은 화염/마법 계열). 중심부는 4구역의 몬스터가 모두 섞여서 출몰
  - 미궁/2층 입장 시 중심부 또는 중간 고리에 랜덤 배치되고, 미로 자체가 매번 새로 생성되므로 포탈까지 몇 걸음이 필요한지는 입장할 때마다 달라짐
  - **최초 입장 시에도** 확률적으로 전투가 발생할 수 있고, 이후 이동할 때도 매번 같은 확률로만 전투가 발생 (포탈로 향하는 이동은 전투 없이 항상 안전)
  - 각 이동 선택지에는 "전투 확률 55%" 또는 포탈인 경우 "전투 없음"이 함께 표시되어, 어느 방향이 안전한지 미리 알 수 있음
  - 동서남북 끝에 포탈비석이 있으며, 처음 발견하면 경험치 +2 획득. 1층에서는 "이 포탈로 2층 입장"을 선택하면 그 포탈의 테마와 동일한 몬스터만 나오는 **2층 전용 미궁**으로 들어감 — 즉 2층은 방향에 따라 완전히 별개인 4개의 미궁으로 나뉨
  - **2층**은 아직 그 다음 층으로 넘어가는 기능 없이(추후 이어서 구현 예정), 포탈 도달 시 경험치 +2와 "다음 구간은 준비 중" 안내만 표시됨. 대신 2층의 포탈에서 **"1층으로 귀환"**을 선택할 수 있음 (미궁 내부 시계 누적 7일이 지나면 이 선택지가 사라지고 더 이상 1층으로 못 돌아감)
  - **최초 진입을 제외한 모든 역행은 항상 재사용이 원칙**: 1층↔2층을 오갈 때마다 새 미로를 만들지 않고, 그 자리(1층, 그리고 2층은 방향별로 각각)를 떠날 때 마지막 상태를 저장해뒀다가 나중에 같은 곳으로 돌아오면 그대로 이어서 사용함 — 포탈 재파밍 악용을 다시 열지 않기 위한 원칙
  - **몬스터 등급은 1등급이 최강, 9등급이 최약인 등급제** (숫자가 작을수록 강함). 층(F)이 깊어질수록 더 강한(숫자가 작은) 등급을 목표로 몬스터가 골라짐 — 1층은 9·8등급이 주류(약 80%)에 가끔 7등급(약 20%), 깊은 층일수록 목표 등급이 1등급 쪽으로 수렴하고 9층 이후는 항상 1등급만 등장(최댓값 고정)
  - **미궁 내부 시계**: 게임 내 1시간 = 실시간 5초(마을 시계보다 훨씬 빠름, 배속 조절 불가). 입장 시점부터 누적으로 흐르고 층을 옮겨도 리셋 안 됨. 누적 7일이 되면 1층에 있을 경우 **강제로 마을로 귀환**(전투 중이라도 즉시, 유예 없음)되고, 누적 10일이 되면 2층에 있을 경우 마찬가지로 강제 귀환됨. 그때까지 얻은 레벨/아이템/정수 등은 전부 그대로 유지되고(사망이 아님), 마을 시계는 실제 미궁 체류 기간과 무관하게 "입장한 날 정오"로 고정됨
    - 미궁 안(미궁 지도/전투/그 상태로 연 인벤토리·장비창·정수창)에서도 마을과 같은 "N일차 HH:MM" 형식으로 이 시계가 표시되고, 흐르는 대로 실시간 갱신됨. 다만 이 표시는 향후 상점에서 판매할 "시계" 장비 아이템을 장착해야만 켜지는 기능으로 설계되어 있어, 지금은 그 아이템이 아직 없으므로 테스트를 위해 기본적으로 켜진 상태로만 동작함(`profile.clockItemEquipped`, 추후 실제 장비 시스템으로 교체 예정)
- 몬스터는 총 24종. 각 몬스터는 4개 구역(북/동/남/서) 중 하나에 소속되어 있어 같은 구역이라도 매번 다른 몬스터를 만날 수 있음
  - 그중 "오크"(5등급, 남쪽 구역)는 원래 플레이어 종족이었다가 몬스터로 전환됨 — 아래 종족 선택 항목 참고
- 종족별 고정 스텟(체력/마나/공격/방어 보너스): 바바리안, 인간, 엘프, 오크, 드워프
  - **현재 선택 가능한 종족은 바바리안뿐**. 나머지(인간/엘프/드워프)는 종족 선택 화면에 "잠김" 배지가 붙은 채로 표시되며 클릭해도 선택되지 않음(추후 공개 예정). 오크는 몬스터로 전환되어 종족 선택 목록에서 아예 빠졌지만, 과거에 오크로 생성된 기존 캐릭터는 영향 없이 그대로 동작함(내부적으로 오크 종족 정의 자체는 유지되고, 신규 생성 화면에서만 제외됨)
- 플레이어 vs 몬스터 턴제 카드 배틀 (공격/방어/회복 카드), 마나 기반 카드 사용, 자동 적 AI 턴
- 몬스터 등급(1~9, 1등급이 최강)에 따른 경험치 획득(강한 몬스터일수록 경험치 많음), 같은 이름의 몬스터는 최초 처치 시에만 경험치 지급
- 레벨/경험치는 `localStorage`에 저장되어 브라우저를 다시 열어도 유지됨, 스텟창에 표시
- **영구 사망(퍼머데스)**: 전투에서 패배하면 레벨/경험치/인벤토리/장비/정수/마석/발견 도감 등 모든 진행 상황이 초기화되고 메인 메뉴로 돌아감 (로그인 계정도 클라우드 저장분이 함께 초기화됨)
- **전투 스킵**: 전투 시작 시 실제 게임 엔진으로 150회 시뮬레이션을 돌려 승률을 추정하고, 승률이 99% 이상이면 "전투 스킵" 버튼이 나타남. 누르면 동일한 자동 플레이 로직으로 그 전투를 즉시 끝까지 진행함 (승리를 보장하지 않고 실제 확률 그대로 결과가 나옴)
- **정수(essence) — 흡수형 장착**: 몬스터 처치 시 0.1% 확률로 그 몬스터 고유의 정수가 드랍. 그 자리에서 흡수할지 버릴지만 선택 가능 (별도 보관 없음). 흡수하면 레벨당 1개씩 열리는 슬롯에 순서대로 영구 장착됨 (해제 UI 없음 — 특수한 방법으로만 해제 가능). 각 정수는 드랍된 몬스터의 특성을 반영한 고정 스텟 보너스 + 전용 스킬 카드를 부여
- **장비(무기/방어구/장신구) — 몸에 착용하는 일반 장비**: 정수와 완전히 별개 시스템. 몬스터 처치 시 3% 확률로 드랍되어 인벤토리에 자동으로 담기고, 장비창에서 자유롭게 장착·해제 가능 (해제하면 다시 인벤토리로)
  - **몬스터별 고유 장비**: 드랍되는 장비는 그 몬스터가 소지·장착했을 법한 전용 아이템 (예: 박쥐 → "박쥐 날개 장식", 오크 전사 → "오크의 전투 도끼", 드래곤 → "용의 비늘 갑옷"). 24종 몬스터 모두 각자 다른 장비를 드랍함
- **마석 — 등급별 드랍**: 몬스터 처치 시 50% 확률로 드랍되며, 그 몬스터의 등급(1~9, 1등급이 최강)에 해당하는 마석이 쌓임. 인벤토리에서 등급별로 구분되어 표시됨 (예: "3등급 마석 x2")
- 장착한 정수와 장비의 스텟 보너스는 모두 종족 스텟에 합산되고, 정수 스킬은 전투 덱에 추가됨
- **화면 3분리**:
  - `인벤토리` — 등급별 마석, 미착용 장비, 금화 표시(금화는 드랍되지 않고 표시만)
  - `장비창` — 무기/방어구/장신구 슬롯. 자유롭게 장착·해제
  - `정수 창` — 지금 장착 중인 정수 목록 + 지금까지 발견한 정수 도감(흡수 안 해도 발견 기록은 남음)
- 모든 행동이 로그로 기록되고 화면에 누적 표시

## 클라우드 저장(로그인) 설정

로그인 기능을 실제로 켜려면 무료 Supabase 프로젝트가 하나 필요합니다. 자세한 단계는 [`supabase/README.md`](./supabase/README.md)를 참고하세요. 요약하면:

1. Supabase 프로젝트 생성 후 `supabase/schema.sql` 실행
2. Authentication → Providers → Email에서 **Confirm email** 끄기
3. Project URL / anon key를 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`로 Render 환경변수에 등록 후 재배포 (로컬은 `.env.local`)

이 값들이 없으면 앱은 자동으로 게스트 전용 모드로 동작합니다.
